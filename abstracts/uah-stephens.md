The topic of zero forcing in graph theory has been extensively investigated because the zero forcing number—a graph parameter—has strong connections to the question of the maximum nullity of an adjacency-type matrix for a graph. Zero forcing is a game played on the vertices of a graph in which some vertices start out black, the rest white. If a black vertex has only one white neighbor, it may color that neighbor black, in which case it is called a forcing vertex and its neighbor is said to have been forced; the game continues until all vertices are black, or until there is not another black vertex with a solitary white neighbor.

This talk explores the connections between zero forcing and girth, the length of a shortest cycle in a graph. Work of Davila and Kenter has found a lower bound for the zero forcing number in terms of minimum degree (minimum number of neighbors among all vertices) and girth. We improve upon this lower bound for graphs with relatively large girth, by tying the question of zero forcing to problems involving edge weightings of graphs.

The connection arises by considering, for a graph on which the zero forcing game is played, a subgraph consisting of, roughly speaking, the forcing vertices. Specifically, we investigate the minimum number of edges such a graph can have, given information about its cyclotomic number (number of edges which must be removed to eliminate all cycles). This number turns out to be equal to the minimum possible total value of a member of a certain class of edge weightings, where an edge weighting here means an assignment of a nonnegative integer value to each edge in a graph subject to certain constraints on the sum of the edge weights in each cycle.
